# React Assignments 1-7

Complete React/Vite implementations for college assignments 1 through 7.

## Projects
- Assignment 1 — Personal Portfolio
- Assignment 2 — Student Information Management using Props
- Assignment 3 — Employee Directory using State and Events
- Assignment 4 — Weather Dashboard using OpenWeatherMap API
- Assignment 5 — Online Shopping Cart using useReducer/Context
- Assignment 6 — Task Manager with React Router
- Assignment 7 — Authentication System with simulated JWT

Each assignment is a standalone Vite app inside its own folder.
